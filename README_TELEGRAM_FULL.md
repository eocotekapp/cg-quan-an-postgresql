# Bản v3 Telegram Full

Đã phục hồi nội dung Telegram theo bản cũ:

- Đặt bàn mới: mã, khách, SĐT, ngày, giờ, số khách, bàn, ghi chú, món đặt trước, tạm tính, trạng thái.
- Đơn ship mới: mã, khách, SĐT, địa chỉ, danh sách món, tạm tính, ship, tổng, ghi chú.
- Xác nhận đặt bàn: khách, bàn, ngày, giờ, khung khóa bàn, mã phiên, tiền món đặt trước.
- Hủy/hoàn thành đặt bàn.
- Ship đang làm/đang giao/hoàn thành/hủy.
- Mở phiên bàn, gọi thêm món, thanh toán hoàn thành, nhắc dọn bàn.

Sau khi copy lên Android, chạy:

```bash
pkill node
cd ~/android-server
npm start
```
